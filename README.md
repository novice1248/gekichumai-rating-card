# gekichumai-rating-card

maimai でらっくす・CHUNITHM・オンゲキの3機種のレーティングを1枚の画像にまとめる
非公式ツール。ゲキチュ“ウマイ”度（3機種合算指標）・実ジャケット・単曲レート・
虹レ表示に対応。

**URL**: https://gekichumai-card-3e325b.pages.dev/

## 使い方

1. 上のURLを開き、「初回セットアップ」からブックマークレットを登録する
2. 各NETサイト（maimai・オンゲキはレーティング対象曲ページ、チュウニズムは任意の
   ページ）を開いた状態でブックマークを実行する
3. 取得が終わるとツールのページにデータが届き、ブラウザ内に保存される。
   以後はページを開くだけで表示され、「画像ダウンロード」でPNG/JPEGを保存できる

任意: maimaiのFC/APマークを画像に入れたい場合は、レコード→ジャンル別スコアページ
（見たい難易度ごと）で同じブックマークを実行してから、レーティング対象曲ページで
実行する。やらなくても他の機能に影響はない

レーティング対象曲ページの閲覧には各NETの有料コース（maimai・チュウニズム=
スタンダードコース、オンゲキ=プレミアムコース）が必要。このツールは本人の
ログインセッションでの取得しかできず、課金ゲートを迂回しない。

## 仕組み

- 完全クライアント完結。スコアデータはサーバーに送信されず、利用者のブラウザ内
  （IndexedDB）にのみ保存される
- ブックマークレットはNETサイト上でページを解析し、ジャケットを同一オリジンとして
  取得してbase64でデータに同梱する（詳細は [docs/specs.md](docs/specs.md)）
- 譜面定数は[楽曲情報API](https://reiwa.f5.si/api.html)（非営利利用）で補完し、
  localStorageに24時間キャッシュする。定数が未確定の曲は「12.7?」のように表示される
- データには簡易チェックサムが付き、手で書き換えると画像に「⚠ 検証NG」が出る
  （抑止であり、セキュリティ機能ではない）
- ブックマークレットは実行のたびに本サイトからスクリプトを読み込む。挙動は
  このリポジトリのソース（`bookmarklets/`）で確認できる

## 開発

```bash
# ローカル起動（任意の静的サーバーでよい）
python3 -m http.server 8757
# 個別スクリプト（bookmarklets/<機種>.js が正典）を編集したら統合版を再生成
python3 bin/build-unified.py
# Cloudflare Pagesへのデプロイ
./bin/deploy.sh
```

- 仕様の根拠・出典・未確認事項は [docs/specs.md](docs/specs.md) に集約
- レーティング段位・ゲキチュ“ウマイ”度・枠定員は `src/tiers.js`、スコアランクは
  `src/rank.js`。ゲームのバージョンアップでズレたらそこだけ直す
- NETサイトのHTML構造への依存は `bookmarklets/` に隔離。壊れたらそこだけ直す
